# Referenz-Analyse – 3 TikTok-Erklärvideos

Alle drei: Hochformat 9:16, 65–80 Sekunden, eine KI-artige Erzählstimme ohne Gesicht, 30 fps, am Ende eine Outro-Karte mit TikTok-Logo und Suchleiste mit dem Handle (~3 s).

## Gemeinsamer Aufbau (die Formel)

| Phase | Zeit | Was passiert | Beispiel |
|---|---|---|---|
| 1. Hook / Titel | 0–4 s | Frage oder These + Serienname | „Rennen oder Gehen? Womit wirst du weniger nass?“ / „Alle Nationalitäten erklärt“ / „The Black Death made workers richer, explained using Minecraft“ |
| 2. Setup | 4–15 s | Feste Regeln oder Figuren einführen, mit Namen | „100 m. Gleicher Regen. Kein Wind.“ / „Das ist Richard … das ist Paul“ / „Mitschüler namens Hannes“ |
| 3. Falsche Erwartung | ~10–15 s | Das Publikum wird absichtlich in die falsche Richtung geführt | „Klar, Rennen ist besser, oder?“ / „Hannes meint, man redet genauso“ |
| 4. Eskalation | 15–45 s | Kurze Szenen, jeder Satz bringt eine neue Info, Zwischenstände | Zähler läuft hoch, Einkaufszettel-Begriffe, Seuche → Arbeitermangel |
| 5. Wendung | ~20–35 s | „Aber jetzt kommt das Merkwürdige …“, „Noch nicht.“ | Läufer zuerst schlechter → dann doch besser |
| 6. Auflösung / echte Erklärung | 45–70 s | Der echte Mechanismus, oft „Im echten Leben …“ | „Von vorne gleich, von oben 18 vs. 6“ / „1349 hat der König …“ |
| 7. Pointe | letzte 3–5 s | Ein knackiger Schlusssatz, oft ein Rückbezug auf den Anfang | „Du kannst nicht vor den Tropfen wegrennen – aber vor der Zeit im Regen schon.“ / „Auch neben Milch. Zur Sicherheit.“ |
| 8. Outro | 3 s | TikTok-Logo + Suchleiste mit dem Handle | |

**Sprache:** sehr kurze Hauptsätze (5–10 Wörter), Präsens, „du“-Ansprache, kein Füllwort, Zahlen konkret. Etwa 2,5–3 Wörter pro Sekunde, also ~170–200 Wörter für 70 s.

**Schnitt:** Alle 1,5–3 s ein neues Bild oder eine Animation. Das Bild zeigt immer genau das, was gerade gesagt wird.

## Visuelle Stile

### A – „explainedusing_minecraft“ (Video 1)
- 3D-Minecraft-Render (Blender/Mineimator-Look), Kamerafahrten, Figuren mit Namensschild über dem Kopf
- **Untertitel: ein Wort pro Bild**, sehr groß, weiß, fett (Montserrat/Arial Black-Stil) mit Schatten, im oberen Drittel
- Requisiten als Symbole: Smaragde = Geld, Schild mit Text = Gesetz, Jahreszahl-Schild „1349“

### B – „kurzsimuliert“ (Video 2) – Datensimulation
- Dunkles Navy (#0f1724-artig), flaches Vektor-Design, Strichmännchen mit runden Köpfen
- Zwei Farben stehen für zwei Seiten: Korallenrot (#f2665a) = Option 1, Türkis (#3cc6b8) = Option 2
- HUD oben: Timer „0:24“, Zähler-Karten (Name + Wert + Status-Pill „IM ZIEL“, „TROCKEN“)
- Pills und Labels („100 M“, „GLEICHER REGEN“, „NOCH NICHT.“ in Gelb/Orange, „GLEICHSTAND 31 = 31“)
- Untertitel unten: 2–3 Wörter, weiß, Schlüsselwörter in der Farbe der jeweiligen Seite, Zahlen in Gelb
- Schluss: Karte „ENDSTAND“, dann Balkendiagramme („VON VORNE“, „VON OBEN“) und „UNTERM STRICH“

### C – „timswissen“ (Video 3) – Karten-Storytelling
- Dunkler, strukturierter Hintergrund (Anthrazit mit leichter Vignette), salbeigrüne Karten mit Schatten
- Realistische Einzelobjekte (Tomate, Palatschinke, Flagge), die auf Karten einfliegen, skalieren und rotieren
- Figuren nur als **Namens-Pills** („du“ in Neongrün mit Stern, „Hannes“, „Mutter“ in Grau mit Icon)
- Begriffe: fett, serifenlos auf Papierzetteln; Übersetzung in **grüner kursiver Serifenschrift** („Kartoffeln“, „Sahne“, „erklärt“)
- Titel: weiß + grün kursiv („Alle Nationalitäten *erklärt*“), Kachel-Raster mit Flaggen, Schluss mit leuchtender Kachel
- Keine durchgehenden Untertitel – nur Schlüsselbegriffe
